# rs-detect 详细开发计划

> 关联文档：  
> - 技术方案：`suction_cardboard_plan.md`  
> - 物料清单：`required_materials.md`  
> - 开发过程：`DEVLOG.md`  
>
> 目标：D435 粗定位 + 腕部 D405 精定位，YOLO 检测/分割 + 多视角融合 + RANSAC 平面，驱动末端吸盘吸取单张纸板。

### 实现口径里程碑（与下文 M0–M5 对照）

| 实现称呼 | 含义 | 对应下文 |
|----------|------|----------|
| **实现 M1** | 扫描分路、出流、拍照、录像、双 UI | ≈ 原 M0 出流骨架 + 部分工具 |
| **实现 M2** | SDK 内参 + 用户输入外参 | ≈ 原 M1 标定的软件容器（手眼求解仍待做） |

下文 **M0–M5** 仍为算法/系统总排期；日常提交与验收以 `DEVLOG.md` 的实现 M1/M2 为准。

## 0. 原则与里程碑总览

### 0.1 开发原则

1. **标定先行**：内参 → 双相机外参/手眼 → 再真机闭环。算法可先用录包并行开发。
2. **终测以 D405 为准**：D435 只做粗定位与门控，禁止两相机深度盲平均。
3. **先通路、后精度、再节拍**：单帧可吸 → 多视角稳 → 再优化耗时。
4. **每个阶段有可验收产物**（命令、话题、指标或报告），再进入下一阶段。
5. **安全**：限速、工作空间、门控失败不盲吸；试机需可急停。

### 0.2 里程碑一览

| 里程碑 | 名称 | 退出标准（摘要） |
|--------|------|------------------|
| M0 | 项目骨架与环境 | 双相机按 SN 稳定出流；文档与目录齐套 |
| M1 | 标定完成 | 内参可用；D405 手眼、D435→base 外参就位并抽检 |
| M2 | 检测通路 | D435/D405 YOLO 可跑；ROI→点云→单帧 RANSAC 出吸点 |
| M3 | 多视角融合 | N 视点采集 + 融合平面；重复性优于单帧 |
| M4 | 臂闭环吸取 | 粗定位→多视点→门控→下吸，小样本成功率达标 |
| M5 | 加固与交付 | 日志、配置、失败恢复、简易操作说明 |

建议节奏（可按现场调整）：M0～M1 约 1～1.5 周；M2～M3 约 1.5～2 周；M4～M5 约 1～1.5 周。与标定量并行时，检测/融合可在录包上提前启动。

```
物料填写 ──► M0 环境/出流 ──► M1 标定 ──► M2 YOLO+单帧平面
                 │                │              │
                 └─ 录包 ─────────┴─ 离线算法 ───┘
                                              ▼
                                    M3 多视角融合
                                              ▼
                                    M4 臂闭环吸取
                                              ▼
                                    M5 加固交付
```

## 1. 仓库与模块规划

### 1.1 建议目录（落地时按此创建）

```text
rs-detect/
├── docs/                    # 方案、物料、本开发计划、标定报告
├── config/                  # 相机 SN、分辨率、外参、门控阈值、轨迹
├── calibration/             # 标定原始数据、结果 yaml/json
├── data/                    # 录包、样张、YOLO 数据集（可 gitignore 大文件）
├── models/                  # YOLO 权重
├── scripts/                 # 一键出流、录包、标定辅助、离线回放
└── src/rs_detect/           # 主代码（包名可定为 rs_detect）
    ├── camera/              # RealSense 封装（按 SN 打开 D435/D405）
    ├── calib/               # 内参加载、手眼/外参变换、TF 工具
    ├── detect/              # YOLO 推理封装
    ├── geometry/            # Align、Mask→点云、RANSAC、融合
    ├── motion/              # 多视点轨迹、与臂接口适配
    ├── pipeline/            # 粗定位→精定位→门控 状态机
    └── app/                 # CLI / ROS 节点入口
```

### 1.2 配置项（`config/` 最小集）

| 文件（示例名） | 内容 |
|----------------|------|
| `cameras.yaml` | D435/D405 SN、分辨率、fps、对齐开关 |
| `extrinsics.yaml` | `T_base_d435`、`T_flange_d405`（或 tcp） |
| `pipeline.yaml` | 工作距、N 视点、门控阈值、法向限幅、有效点数下限 |
| `yolo.yaml` | 权重路径、类别名、置信度、imgsz |
| `robot.yaml` | 臂接口类型、速度上限、观测/吸取偏置 |

## 2. 阶段明细

### 阶段 M0：环境与出流骨架

**目标：** 两台相机可按序列号稳定打开；仓库可编译/可 import；录包工具可用。

| 任务 | 说明 | 产出 |
|------|------|------|
| M0.1 确认物料最小包 | SN、臂接口、OS/ROS、现有驱动 | 更新 `required_materials.md` 勾选 |
| M0.2 依赖安装 | `librealsense`、`pyrealsense2`；若 ROS 则 `realsense2_camera` | 环境说明写入 `docs/setup.md`（后续补） |
| M0.3 双相机出流 | 按 SN 同时开 D435 + D405；彩图+深度+Align | `scripts/open_cameras.py` 或 launch |
| M0.4 录包 | 同步保存彩图、深度、（可选）臂位姿时间戳 | `scripts/record_bag.py`；样例包入 `data/` |
| M0.5 包结构 | 创建 `src/rs_detect` 空模块与 README | 可 `pip install -e` 或 ROS 包构建通过 |

**验收：**

- [ ] 两相机同时出流 ≥ 5 min 无掉流
- [ ] 能区分 SN→角色（场景 / 腕部）
- [ ] 录包可回放一对齐帧

**依赖：** 用户提供 D435/D405 SN；主机已接好相机。

---

### 阶段 M1：标定（强制关卡）

**目标：** 内参可用；两套外参进入 `config/extrinsics.yaml`，误差可复现抽检。

#### M1.A 内参

| 任务 | 说明 | 产出 |
|------|------|------|
| M1.A1 读取出厂内参 | 目标分辨率下的 color/depth intrinsics | `calibration/intrinsics_*.json` |
| M1.A2（可选）精标/校验 | 棋盘格或厂家工具；对比重投影误差 | 标定报告小节 |
| M1.A3 Align 验证 | 彩图边缘与深度边缘目视/采样对齐 | 截图或笔记 |

#### M1.B D405 眼在手

| 任务 | 说明 | 产出 |
|------|------|------|
| M1.B1 标定板流程 | 多姿态采样（建议 ≥ 15～20 组） | 原始图 + 臂位姿日志 |
| M1.B2 求解 `T_flange_cam` | OpenCV / easy_handeye 等 | 写入 `extrinsics.yaml` |
| M1.B3 抽检 | 已知板位置复测；或抬臂后板在相机系预测 vs 实测 | 误差表（平移/旋转） |

#### M1.C D435 → base

| 任务 | 说明 | 产出 |
|------|------|------|
| M1.C1 标定 | 标定板在基座系已知位姿，或臂尖触点辅助 | `T_base_d435` |
| M1.C2 与 D405 交叉验证 | 同一板角点：D435 投到 base vs D405+手眼投到 base | 偏差统计 |

#### M1.D 文档

| 任务 | 产出 |
|------|------|
| 标定操作步骤与复查周期 | `docs/calibration_guide.md`（本阶段末补） |
| 本次结果摘要 | `calibration/REPORT.md` |

**验收：**

- [ ] 内参与 Align 在目标分辨率下确认
- [ ] 手眼、场景外参文件就位且版本可追溯
- [ ] 交叉验证：同名点在 base 下偏差在约定阈值内（初值可先定平移数 mm～cm 级，再收紧）

**阻塞规则：** 未完成 M1.B / M1.C，不得进入 M4 真机吸取；M2/M3 可用录包 + 占位外参离线推进。

---

### 阶段 M2：YOLO + 单帧平面通路

**目标：** 任意单帧（先 D405，再 D435）完成「检测 → Mask → 点云 → RANSAC → 吸点候选」。

| 任务 | 说明 | 产出 |
|------|------|------|
| M2.1 数据 | 采集 D435/D405 纸板样张；标注 detect 或 segment | `data/yolo/` |
| M2.2 训练/选型 | 轻量 YOLO；双相机可共用权重，域差大则微调腕部 | `models/cardboard_yolo*.pt` |
| M2.3 推理封装 | 统一接口：`detect(image) → boxes/masks` | `src/rs_detect/detect/` |
| M2.4 Mask→点云 | Align 深度 + 内参反投影；滤无效深度 | `geometry/mask_to_cloud.py` |
| M2.5 RANSAC 平面 | 平面方程、inlier、质心、法向（朝向相机） | `geometry/plane_ransac.py` |
| M2.6 单帧管线 | CLI：输入图/录包 → 输出 `c, n, score` | `scripts/run_single_frame.py` |
| M2.7 D435 粗定位模块 | YOLO +（可选）粗 RANSAC → `p_coarse` | `pipeline/coarse_localize.py` |

**验收：**

- [ ] 典型纸板：YOLO 召回稳定（自定：如置信度阈值下连续 50 帧漏检率可接受）
- [ ] 单帧 RANSAC inlier 比例与有效点数过阈值
- [ ] 可视化：框/Mask、平面法向、吸点投影回彩图

**本阶段不做：** 多视点轨迹、真实下吸。

---

### 阶段 M3：多视角融合

**目标：** 腕部 N 视点短停采集，点云级 + 平面参数级融合，重复性优于单帧。

| 任务 | 说明 | 产出 |
|------|------|------|
| M3.1 视点生成 | 相对粗目标生成 N=3～5 个邻近视点（平移 2～4 cm 级） | `motion/viewpoint.py` + `config/pipeline.yaml` |
| M3.2 采集状态机 | 到位→短停→抓图+位姿→下一视点 | `pipeline/multiview_capture.py` |
| M3.3 点云融合 | 变到 base 后体素/加权融合（类 TSDF 或体素均值） | `geometry/voxel_fuse.py` |
| M3.4 平面融合 | 每视点 π_i 加权/一致性融合；与融合点云 RANSAC 交叉验证 | `geometry/plane_fuse.py` |
| M3.5 离线评测 | 同场景重复 10+ 次：吸点标准差、法向角标准差 | `docs/metrics_m3.md` 或表格 |
| M3.6 失败策略 | 有效点不足 / 视点间不一致 → 补视点或回退粗定位 | 写入 pipeline |

**验收：**

- [ ] 融合结果可视化（多视点云叠加不应明显“重影”过大）
- [ ] 相对单帧：吸点/法向重复性有量化改善（记录具体数字）
- [ ] 人为遮挡或单帧空洞时，融合仍能出可用平面的比例提升

**注意：** 融合阶段仍可用「模拟位姿 / 录包位姿」验收几何；接真臂轨迹放到 M4。

---

### 阶段 M4：机械臂闭环吸取

**目标：** 完整链路真机跑通，小样本成功率达标。

| 任务 | 说明 | 产出 |
|------|------|------|
| M4.1 臂适配层 | 按实际 SDK/ROS 封装：读位姿、运动到点、速度限制 | `motion/robot_adapter.py` |
| M4.2 观测运动 | 执行 M3 视点；每点短停与时间戳对齐 | 联调记录 |
| M4.3 门控 | `c*` vs `p_coarse` 距离/法向；双相机 YOLO 命中数 | `pipeline/gate.py` |
| M4.4 吸姿生成 | 法向限幅；接近高度、吸盘偏移 | `pipeline/suction_pose.py` |
| M4.5 吸取动作 | 下压/开启真空/抬起（按现场 IO） | 与现有气动接口对接 |
| M4.6 全流程状态机 | A→B→C→D→E；失败重试次数可配 | `pipeline/fsm.py` + 主入口 |
| M4.7 现场试验 | 固定纸板位姿集 + 随机小扰动位姿集 | 试验记录表 |

**验收（建议初值，可按现场改）：**

- [ ] 连续 20 次固定位姿吸取成功率 ≥ 90%
- [ ] 门控应拒绝的错误场景（空桌、目标过偏）能拒绝
- [ ] 平均单次耗时有记录（不先卡死指标）
- [ ] 急停与限速策略有效

**安全检查清单（试机前）：**

- [ ] 速度/加速度上限已设
- [ ] 工作空间限位
- [ ] 门控失败默认不下降
- [ ] 人员站位与急停责任明确

## 3. 并行工作流

| 轨道 | 可并行内容 | 依赖 |
|------|------------|------|
| A 硬件/标定 | M1 标定采集与求解 | 相机+臂+标定板 |
| B 数据/YOLO | 样张、标注、训练（M2.1–M2.2） | 出流或手机/相机样张 |
| C 几何算法 | Mask→点云、RANSAC、融合离线（M2.4–M3.4） | 录包；外参可用单位阵占位 |
| D 臂接口 | Adapter 读写与安全点位（M4.1） | 臂控制方式文档 |

合并点：M2.6 后接入真外参；M3 后接入真轨迹；M4 统一联调。

## 4. 接口约定（开发期冻结草稿）

### 4.1 粗定位输出

```text
CoarseResult:
  p_coarse: (x, y, z) in base
  n_coarse: (nx, ny, nz) optional
  yolo_conf: float
  timestamp: ...
```

### 4.2 单视点观测

```text
ViewObservation:
  T_base_cam: 4x4
  mask / box
  points_cam or points_base
  plane_i (optional)
  timestamp
```

### 4.3 精定位输出

```text
FineResult:
  c_star: (x, y, z) in base
  n_star: (nx, ny, nz)
  inlier_ratio, num_points
  fuse_quality: float
  gate_ok: bool
  gate_reason: str
```

具体字段在编码时落入 `src/rs_detect` 的 dataclass / msg，变更需同步改本文档。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 纸板弱纹理，D405 深度大面积无效 | 平面失败 | 补光；多视角；有效点门控；略调工作距 |
| 手眼误差 / 工装松动 | 吸偏 | M1 交叉验证；定期复查；测时短停 |
| 吸盘挡视野 | Mask 残缺 | 安装偏置；仅用可见区吸点 |
| YOLO 域差（俯视 vs 腕部） | 腕部漏检 | 腕部数据微调；颜色备份通道 |
| 臂–相机时间不对齐 | 融合重影 | 短停；时间戳对齐；弃用运动中帧 |
| 过度追求整板中心 | FOV 不足 | 坚持可见区可吸点（方案已定） |
| 两相机深度盲目融合 | 精度变差 | 代码层禁止；仅门控 |
