# 腕部吸盘吸纸板感知方案

> 项目：`rs-detect`  
> 传感器：场景相机 RealSense **D435** + 腕部相机 RealSense **D405**（末端吸盘）  
> 目标：定位单张纸板并给出可执行的吸取位姿（位置 + 限幅姿态）

---

## 1. 场景约束

| 项 | 约定 |
|----|------|
| 物体 | 单张纸板，**不存在叠板** |
| 背景 | **无与纸板近色的其他物体** |
| D435 | 固定场景相机，**粗定位** + 一致性门控 |
| D405 | 装在末端吸盘附近，**最终测距 / 精定位以它为准** |
| 测距原则 | 禁止 D435 与 D405 深度简单加权平均 |

---

## 2. 方案总览

技术主线：

**双相机 YOLO 检测 → 腕部多位姿观测 → 带位姿的多视角几何融合 → RANSAC 平面吸点 → 手眼变换下发**

| 层级 | 传感器 | 角色 |
|------|--------|------|
| 感知检测 | D435 + D405 | 同一套 YOLO 检出 `cardboard`（框 / Mask） |
| 几何融合 | 腕部多帧 D405 | 多视角融合，稳定平面与吸点 |
| 执行门控 | 手眼 + 机械臂 | 基座系吸姿下发；D435 仅粗定位与门控 |

```
D435 YOLO → 粗位姿
    → 腕部到位（约 15–40 cm）
    → N 个短停视点：YOLO Mask + 深度 + T_base_cam
    → 多视角点云融合 / 平面参数融合
    → 吸点 c* + 法向 n*（限幅）
    → 与 D435 门控
    → 下吸
```

---

## 3. 为何不用点云聚类

纸板为大面积平面。即便当前约定不叠板，DBSCAN 等聚类仍容易把纸板与桌面（若共面/近距连通）粘成同一连通域，且平面纹理弱时分割不稳定。

本任务采用：**2D YOLO（或 Mask）约束 ROI + 深度点云 + RANSAC 平面拟合**，专治平面件吸取。

---

## 4. 分阶段流程

### 阶段 A：D435 粗定位（YOLO）

1. D435 彩色图跑 **YOLO**（优先分割模型出 Mask；仅检测框时需膨胀为 ROI）。
2. Mask / ROI 内取深度点云，可选一次 RANSAC，得到基座系粗位置 \(p_{\text{coarse}}\) 与粗法向 \(n_{\text{coarse}}\)。
3. 规划腕部观测位姿：使纸板大致落入 D405 画幅中央，工作距约 **15–40 cm**（落在 D405 有效范围 7–50 cm 内）。
4. **D435 结果不进入最终吸点数值**，只用于导航与阶段 E 门控。

**标定要求：** D435 相对机器人基座的外参；统一到 `base` TF。

### 阶段 B：腕部多视角采集

到位后不单帧决策，执行短轨迹多视角采集（多视角融合的数据来源）：

1. 在粗目标上方采集 **N = 3～5** 个邻近视点  
   - 例如水平平移 2–4 cm 的小折线 / 扇形，或绕工具轴轻微转角。
2. 每个视点：**短停** → 记录时间戳对齐的  
   `(彩色图, 深度图, TCP/相机位姿 \(T_{\text{base}\leftarrow\text{cam}}\))`。
3. 每帧 D405 彩色图跑 **同一套 YOLO 权重** → 得到 \(\text{Mask}_i\)。  
   - 现场可将颜色阈值作备份；方案主路径以 YOLO 为准，便于跨视角稳定 ROI。

**约束：** 轨迹小、速度低、短停；各视点对同一张纸板保持足够重叠。

**标定要求：** D405 眼在手（eye-in-hand）外参；图像与机器人时间戳对齐。

### 阶段 C：多视角融合（核心）

对每个视点 \(i\)：

1. 深度与彩色 **Align** 后，用 \(\text{Mask}_i\) 反投影得到相机系点云 \(P_i^{\text{cam}}\)。
2. 用 \(T_{\text{base}\leftarrow\text{cam},i}\) 变换到基座系 \(P_i^{\text{base}}\)。
3. 剔除无效深度与明显离群点。

#### C1. 点云级多视角融合

- 将 \(\{P_i^{\text{base}}\}\) 融入统一体素栅格 / 截断加权融合（类 TSDF，或按视距加权的体素平均）。
- 同体素多帧观测加权平均 → 抑制 D405 随机噪声、单帧空洞、短停后的微抖毛刺。
- 输出融合点云 \(P_{\text{fuse}}\)。

#### C2. 平面参数级融合

- 各视点单独 RANSAC，得平面 \(\pi_i = (n_i, d_i)\) 与吸点候选 \(c_i\)。
- 在基座系做 **协方差加权 / 一致性门控融合**（法向夹角、点到平面距离）→ \(\pi^\star,\, c^\star\)。
- 再对 \(P_{\text{fuse}}\) 做一次 RANSAC，与 \(\pi^\star\) 交叉验证；偏差大则补采或退回阶段 B。

**能力边界（务必写清）：**

- 多视角融合主要降低 **传感器随机噪声与偶发失效**。
- 若腕部工装弹性振动使真实相机位姿偏离 FK + 手眼外参，融合可能抹平，也可能 smearing；根本手段仍是 **刚性安装、测时短停、外参定期校验**。

### 阶段 D：吸点与姿态

| 量 | 定义 |
|----|------|
| 吸点 \(c^\star\) | 融合平面在 D405 可见区域内的中心（Mask 内有效点质心或融合平面中心） |
| 姿态 | 由融合法向 \(n^\star\) 构造吸盘接近姿态，**小角度限幅**，避免单帧法向抖动 |

说明：

- **不追求整板几何中心**。大纸板在小 FOV 下看不全时，视野内平坦可吸区域中心即可。
- 无叠板时无需“近端分层”；Mask 内有效点数 / RANSAC inlier 比例过低则不盲吸。

### 阶段 E：跨相机门控与执行

1. 手眼 + 当前正解：将 \(c^\star,\, n^\star\) 转到 `base`（若融合已在 `base` 则直接下发）。
2. 门控（建议）：
   - \(\|c^\star - p_{\text{coarse}}\|\) 与法向夹角不超过阈值（按标定精度整定，例如距离数厘米级）。
   - D435 YOLO 必须检出；D405 多视点中至少 **K** 帧检出。
3. 通过后门控失败则重观测或退回阶段 A；通过则下吸。

**禁止：** D435 / D405 深度盲平均。跨相机只做 **检测一致 + 几何门控**。

---

## 5. 模块与技术栈

1. **YOLO 纸板检测 / 分割**（D435 + D405 共用权重；域差大时可对腕部视角微调）
2. **眼在手标定 + 场景相机外参 + 时间戳同步**
3. **腕部短轨迹多视点采集**
4. **多视角点云融合（体素 / TSDF）+ 平面参数融合**
5. **RANSAC 平面 → 吸点 / 限幅法向**
6. **D435 粗定位与跨相机一致性门控**
7. **运动规划与吸取执行**

---

## 6. 避坑指南

| 项 | 说明 |
|----|------|
| D405 无投影激光 | D405 为短基线被动双目，**无 Laser Power**。黑纸板 / 覆膜反光靠补光、曝光与空间/时间滤波，而非加大激光。 |
| FOV 偏小 | 大纸板可能看不全；RANSAC 仍可拟合可见平面。吸点用可见区中心即可，非工艺要求则不必全板扫描拼接。 |
| 最佳工作距 | 约 **7–50 cm**；终测建议 **15–40 cm**，避免贴太近失焦/超近距失效。 |
| 吸盘挡视野 | 安装时让镜头相对吸盘中心偏置，遮挡留在画面边缘。 |
| 纹理弱 → 深度空洞 | 短停 + 多帧/多视角融合；有效点过少则换角度或略抬高重试。 |
| 工装抖动 | 测距短停；融合抑传感器噪声，不能替代刚性固定与标定维护。 |
| 法向噪声 | 多视点融合后再限幅使用，避免末端姿态抖动。 |

---

## 7. 明确不做

- 用点云聚类（如 DBSCAN）做纸板/桌面/分层分割
- D435 与 D405 深度简单加权平均当作“高精度融合”
- 无工艺要求时强制全板拼接求几何中心
- 将场景相机深度作为最终吸点真值

---

## 8. 预期收益与精度预期

| 项目 | 预期 |
|------|------|
| 最终距离精度量级 | 仍主要受 **D405** 约束（约 ±2% 量级量级参考，视距离与标定而定） |
| 多视角融合收益 | 更好的重复性、更少空洞与单帧毛刺；**不是**把绝对精度提升一个数量级 |
| YOLO 收益 | 双相机稳定 ROI，方案可演示、可扩展，不依赖“仅颜色分割”的叙事 |
| D435 收益 | 更快对准、减少腕部盲目搜索；门控降低吸错位置风险 |

---

## 9. 一句话定稿

**D435-YOLO 粗找 → 腕部多视点 YOLO-Mask → 带手眼位姿的多视角深度融合 → 融合平面求吸点与限幅法向；终测以 D405 为准，D435 只做粗定位与一致性门控。**
